- **Diseño Minimalista**: Interfaz limpia y moderna con efectos visuales sofisticados

## 🚀 Cómo usar

1. Abre el archivo `index.html` en tu navegador web
2. La página es completamente funcional y estática
3. El formulario de citas muestra una confirmación visual (en producción se conectaría a un backend)

## 🎨 Tecnologías

- HTML5
- CSS3 (con animaciones y efectos modernos)
- JavaScript vanilla (sin dependencias)
- Google Fonts (Poppins)

## 📱 Características Visuales

- Fondo animado con patrones de dientes que se mueven al hacer scroll
- Ilustraciones SVG de estructuras dentales
- Efectos de hover y transiciones suaves
- Diseño con gradientes y sombras modernas
- Modal de confirmación para citas

## 🌐 Deploy

Para publicar la página:
1. Sube los archivos a cualquier hosting web
2. O usa servicios como GitHub Pages, Netlify, o Vercel

No requiere configuración de servidor ni base de datos.
